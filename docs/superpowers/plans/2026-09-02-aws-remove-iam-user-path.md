# PR 3b — Remove the legacy AWS IAM-user + access-key path

**Epic:** AWS role-based credentials (`epic/aws-per-user-permissions`)
**Spec:** [design](../specs/2026-09-01-aws-role-based-credentials-design.md) §2, §5, "Delivery shape"
**Branch:** `feature/aws-remove-iam-user-path` (base `epic/aws-per-user-permissions`)
**Predecessors merged:** PR 1 (#454), PR 2a (#455), PR 2b (#456), PR 3a (#457 — UI is now Roles-Anywhere-only)

## Why now
After 3a the UI and the connector/ingestion path no longer touch the access-key
shape: `ConnectorFactory` depends only on `ConnapseAwsCredentials`, and the
access-key shape is reached *only* through `ConnapseAwsCredentials.ReadStoredAsync`
(the `GetAsync`/`GetSecretAsync` branch) and `ProviderSetupReader`. So the legacy
path can be deleted with no fallback (pre-release, no users).

## Design decision — the reader's timestamp read
`ProviderSetupReader` needs exactly **existence + `CreatedAt` + `VerifiedAt`** from
the stored credential (it never reads `PublicId`). No Roles-Anywhere read exposes
timestamps today. Rather than bloat `GetRolesAnywhereAsync`, add a small
shape-agnostic read: `ProviderCredentialStatus(DateTime CreatedAt, DateTime? VerifiedAt)`
+ `GetStatusAsync(provider)`. The reader uses that; it works for the RA shape now
and any future shape.

### Phase 1/6 — Add the shape-agnostic status read; repoint the reader
**Goal:** `ProviderSetupReader` stops calling `GetAsync`.
- Add `ProviderCredentialStatus` record + `IProviderCredentialStore.GetStatusAsync`; implement in `PostgresProviderCredentialStore` (projects `CreatedAt`/`VerifiedAt`, any shape).
- Repoint `ProviderSetupReader.StoredCredentialAsync` → `GetStatusAsync`; retype `NotWorkingYet(...)` and the `stored` consumers to `ProviderCredentialStatus`.
**Done when:** build clean; reader no longer references `GetAsync`/`ProviderCredentialInfo.PublicId`.

### Phase 2/6 — Delete the three legacy store methods + the runtime branch
**Goal:** `GetAsync`, `GetSecretAsync`, `SaveAsync` gone from interface + impl; runtime access-key branch gone.
- Delete the three signatures (`IProviderCredentialStore`) and impls (`PostgresProviderCredentialStore`).
- Remove `PublicId` from `ProviderCredentialInfo`; fix `SaveRolesAnywhereAsync`'s returned `ProviderCredentialInfo` (drop the blank `PublicId`) and its `PublicId`/`SecretProtected` cl-earing writes.
- Delete the access-key branch in `ConnapseAwsCredentials.ReadStoredAsync` (lines ~147-153) — once the RA block doesn't match, return null → ambient fallback.
**Done when:** build clean; no production reference to the three methods or `PublicId`.

### Phase 3/6 — Drop the entity columns + CHECK constraint (migration)

Snapshot regenerated by the tool.
**Done when:** migration builds; snapshot no longer declares the two columns.
