# Command-line tool

The `connapse` command-line tool lives in its own repository, [Destrayon/connapse-cli](https://github.com/Destrayon/connapse-cli), with its install steps and command reference. It talks to your server only through the [REST API](rest-api.md), so anything it does, a script can do too.
