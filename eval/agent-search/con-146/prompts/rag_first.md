
## Which search to use
- Use `search_knowledge` first when the question describes a situation, reason, process or event in its own words and you do not know the exact words the records use ("what caused", "how does", "what happens when", "who committed to").
- Use `grep_files` first when the question contains an exact name: a person, customer, project, ticket ID, error code, file name, or a literal string or number.
- Once one search gives you a name or a record, switch freely: grep for a name that `search_knowledge` surfaced, or read a record that grep found.
- If one kind of search comes up empty or off-topic after two tries, try the other.
